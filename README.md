# Homebrew tap

Homebrew formulae for applications by Michael Collins.

## Installing

```sh
brew tap mfcollins3/tap
brew install naked-time
```

Or in one step: `brew install mfcollins3/tap/naked-time`.

## Formulae

| Formula | Description | Platforms |
|---------|-------------|-----------|
| `naked-time` | Pomodoro-based time management and tracking | macOS (Apple silicon), Linux (x64, ARM64) |

On Linux, `naked-time` needs the ALSA library from your system package manager
(`libasound2` on Debian/Ubuntu, `alsa-lib` on Fedora).

The formulae are generated by the release workflows of the applications they
install. Do not edit them by hand.
